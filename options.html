Joplin Clipper Plus — Settings

Joplin desktop → Tools → Options → Web Clipper → make sure the service is enabled.
The popup opens with these already selected — click the icon, then just Clip. You can still change them in the popup each time. The notebook list needs the token above (Joplin must be running).

Site rules (optional)

If a site clips badly (menus, ads or comments come along, or the text is missing), you can tell the clipper which part of that site's page is the article. Your rules are used before the built-in ones.
